# SabunCopy

Finder の統合の挙動が未だによくわからない...
エクスプローラーライクな「差分だけコピー」「上書き前の確認」を補う、macOS 用の小さなコピーツールです。

## できること

- コピー元（ファイル・フォルダ）とコピー先をドラッグ&ドロップで指定。フォルダ階層は維持
- **動作**：コピー／移動（移動はコピーして内容を照合してから、移動元をゴミ箱へ）
- **比較**：同名ファイルを何で比べるか。空欄（—）／更新日時／サイズ
  - 更新日時なら「新しい／古い」、サイズなら「大きい／小さい」のどちらを残すかを選ぶ
  - 比べた値が同じなら、確認せずスキップ
- **処理**：比較が空欄のときの扱い。確認（1 件ずつ・「以降すべてに適用」あり）／上書き／スキップ／両方残す。比較を選ぶと「残す」だけになる
- 実行前に **差分を確認**（新規・上書き・同一・スキップ・確認・両方残す）
- コピー先の **最近使ったフォルダ** と **お気に入り**
- 歯車（ツールバー右端）の設定：ハッシュ照合（SHA-256）／最前面に固定／処理後に閉じる。どれも次回起動時に保持
- Finder の右クリック（サービス）、Dock アイコンへのドロップからコピー元を追加
- 日本語・英語に対応（システムの言語に従う）。

## ビルド

Xcode または Command Line Tools が必要です（macOS 13 以降）。

```sh
./build_app.sh            # SabunCopy.app をビルド
./build_app.sh --install  # ビルドして ~/Applications へ入れ、Finder のサービスを登録
```

SwiftUI の `@State` マクロは Command Line Tools だけの環境ではビルドできないため、
このプロジェクトでは `@State` を使わず `ObservableObject` で状態を持っています。

## 動作確認

コピー・移動・比較の判定は、実ファイルを一時フォルダに作って検査できます。

```sh
./Tests/run_engine_check.sh
```

更新日時・サイズの「残す」判定、各処理、移動、差分プレビューの判断、安全のための挙動（下記）を 40 項目ほど確認します。
後片付けは、その実行で作った一時フォルダと、移動テストでゴミ箱に入った `sabuntest_<実行ID>_*` だけを消します（他の実行や、あなたのファイルには触れません）。

## 多言語

画面の文字は `Resources/en.lproj` と `Resources/ja.lproj` の `Localizable.strings` から引きます（キーは日本語の原文）。
翻訳は `Tools/gen_strings.py` の表で管理しています。

```sh
python3 Tools/gen_strings.py          # 表から .strings を生成
python3 Tools/gen_strings.py --check  # ソースに翻訳もれがないか確認
```

言語を足すときは、表に列を足して `LANGS` に加えてください。ドロップダウンの幅は、その言語でいちばん長い表示名に合わせて自動で決まります。

## Finder の右クリックから使う

`--install` で `~/Applications` に入れると、Finder の右クリック → サービス（クイックアクション）に次が出ます。

- SabunCopy：コピー元に追加（英語では “SabunCopy: Add as Source”）
- SabunCopy：コピー先にする（フォルダを選んだとき）

出ない場合は、システム設定 → キーボード → キーボードショートカット → サービス → ファイルおよびフォルダ で有効にしてください。

## 安全のための設計

- **計画が作れなければ何もしない**：フォルダの中に読めないものがあれば、一部だけをコピーせず、実行前に中止します。
- **一時ファイル経由で書く**：コピー先と同じフォルダの一時ファイル（`.sabun-*.tmp`）へ書き、照合（有効なとき）まで済んでから最終の名前に切り替えます。途中で失敗しても、最終の名前に中途半端なファイルは残りません。上書きのときも、新しい内容が揃うまで既存のファイルには触れません。強制終了などで一時ファイルが残ることはあります（自動では消しません）。
- **シンボリックリンクの上書き**：新しいリンクを一時の名前で作り、`rename` で一度に置き換えます。
- **自分自身への書き込みを防ぐ**：コピー先がコピー元の内側、または同じ場所のときは、シンボリックリンクを解決した実体のパスで判定して中止します。

## 注意

- 署名はアドホック署名です（自分でビルドして使う前提）。
- 移動は「コピー → 照合 → 移動元をゴミ箱へ」です。完全削除はしません。
- 比較で「同じ」と判断するのは、選んだ値（更新日時またはサイズ）だけです。中身の一致までは見ません。
  移動のときだけ、同一とみなしたファイルの移動元を片付ける前に内容（ハッシュ）を確かめます。
- 大きい 1 ファイルのコピー中の進捗表示は未対応です（ファイル単位）。
