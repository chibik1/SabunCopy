# 差分コピー（SabunCopy）

Finder のコピーに足りない「差分だけコピー」「上書き前の確認」を補う、macOS 用の小さなコピーツールです。
Windows の FireFileCopy / TeraCopy のような使い方を目指しています。

## できること

- コピー元（ファイル・フォルダ）とコピー先をドラッグ&ドロップで指定。フォルダ階層は維持
- **動作**：コピー／移動（移動はコピーして内容を照合してから、移動元をゴミ箱へ）
- **比較**：同名ファイルを何で比べるか。空欄（—）／更新日時／サイズ
  - 更新日時なら「新しい／古い」、サイズなら「大きい／小さい」のどちらを残すかを選ぶ
  - 比べた値が同じなら、確認せずスキップ
- **処理**：比較が空欄のときの扱い。確認（1 件ずつ・「以降すべてに適用」あり）／上書き／スキップ／両方残す。比較を選ぶと「残す」だけになる
- 実行前に **差分を確認**（新規・上書き・同一・スキップ・確認・両方残す）
- コピー先の **最近使ったフォルダ** と **お気に入り**
- 歯車（ツールバー右端）の設定：ハッシュ照合（SHA-256）／最前面に固定／処理後に閉じる。どれも次回起動時に保持
- Finder の右クリック（サービス）、Dock アイコンへのドロップからコピー元を追加

## ビルド

Xcode または Command Line Tools が必要です（macOS 13 以降）。

```sh
./build_app.sh            # SabunCopy.app をビルド
./build_app.sh --install  # ビルドして ~/Applications へ入れ、Finder のサービスを登録
```

SwiftUI の `@State` マクロは Command Line Tools だけの環境ではビルドできないため、
このプロジェクトでは `@State` を使わず `ObservableObject` で状態を持っています。

## 動作確認

コピー・移動・比較の判定は、実ファイルを一時フォルダに作って検査できます。

```sh
./Tests/run_engine_check.sh
```

更新日時・サイズの「残す」判定、各処理、移動、差分プレビューの判断を 30 項目ほど確認します。
移動のテストでゴミ箱に入った `sabuntest_*` のファイルは、終了時に自動で片付けます。

## Finder の右クリックから使う

`--install` で `~/Applications` に入れると、Finder の右クリック → サービス（クイックアクション）に次が出ます。

- 差分コピー：コピー元に追加
- 差分コピー：コピー先にする（フォルダを選んだとき）

出ない場合は、システム設定 → キーボード → キーボードショートカット → サービス → ファイルおよびフォルダ で有効にしてください。

## 注意

- 署名はアドホック署名です（自分でビルドして使う前提）。
- 移動は「コピー → 照合 → 移動元をゴミ箱へ」です。完全削除はしません。
- 比較で「同じ」と判断するのは、選んだ値（更新日時またはサイズ）だけです。中身の一致までは見ません。
  移動のときだけ、同一とみなしたファイルの移動元を片付ける前に内容（ハッシュ）を確かめます。
- 大きい 1 ファイルのコピー中の進捗表示は未対応です（ファイル単位）。
